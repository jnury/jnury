## Side projects

### NodLight

<img src="https://raw.githubusercontent.com/jnury/NodLight/main/docs/images/deck.png" alt="NodLight strip with five sessions: two waiting, two working, one idle" width="200" align="right">

I run six or seven Claude Code and Codex sessions at once, each in its own Alacritty window. They stop and wait for me without saying so.

[NodLight](https://github.com/jnury/NodLight) is a strip of cards on the edge of the screen, one per session. Orange and blinking means a session needs me, green means it is working, grey means it is idle. Click a card, land in that window. It also shows each session's CPU, memory and I/O.

Windows 11, open source (MIT). The installer is on the [Releases page](https://github.com/jnury/NodLight/releases/latest).

### Furtiv

[Furtiv](https://github.com/jnury/Furtiv) runs command-line tools and PowerShell scripts on Windows without opening a console window. Handy for logon scripts and actions triggered in the background.
